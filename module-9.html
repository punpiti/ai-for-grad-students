Standalone

เลือก pain point ที่เกิดซ้ำ มี input/output ชัด และทดลองได้ด้วยข้อมูลตัวอย่างที่ไม่อ่อนไหว

อย่าเริ่มใหญ่เกินไป

Version 1.0 ควรแก้ปัญหาเดียวให้ปลอดภัยและทำซ้ำได้ ก่อนรวมหลายกระบวนงานเข้าด้วยกัน

Choice architecture

กำหนดคำตอบไว้ก่อนที่งานจะเร่ง

01

DEFAULT

ตัวเลือกที่ใช้ได้อัตโนมัติเมื่อเงื่อนไขปกติครบและความเสี่ยงต่ำ

02

ASK

ต้องถามเจ้าของงานก่อนเมื่อมีหลายทางเลือกหรือการเปลี่ยนแปลงที่ย้อนกลับยาก

03

NEVER

สิ่งที่ห้ามทำ เช่น แต่ง citation เขียนทับข้อมูลดิบ ส่งไฟล์ หรือเปิดเผยข้อมูลลับ

04

ESCALATE

หยุดและส่งให้ผู้มีอำนาจหรือผู้เชี่ยวชาญ เช่น จริยธรรม กฎหมาย สถิติ หรือการตีความเชิงสาขา

Workshop

ประกอบ ทดสอบ และ freeze รุ่น 1.0

  1. 01
    ทำ personal research profile
    ระบุสาขา งานซ้ำ เครื่องมือ ข้อมูล ความเสี่ยง และผู้มีอำนาจตัดสิน
  2. 02
    เขียน workflow card
    กำหนด trigger, input, steps, output, verification, stop condition, fallback และ owner
  3. 03
    จัด research operations
    ใช้ inventory → preview → approval → move-only → manifest เมื่อต้องจัดโฟลเดอร์ และแยก sync, version control กับ backup
  4. 04
    ประกอบ kit
    รวม profile, guardrails, templates, examples, checklists, tests, run record และ changelog
  5. 05
    ทดสอบ failure cases
    ลอง input ขาด ข้อมูลลับ citation ปลอม path ผิด output ซ้ำ และคำสั่งที่ขัดกัน
  6. 06
    Freeze Version 1.0
    บันทึกสิ่งที่ผ่าน สิ่งที่ยังไม่ทดสอบ และเงื่อนไขทบทวนหลังใช้งานจริง
ช่วยฉันสร้าง workflow kit สำหรับงานซ้ำหนึ่งเรื่อง เริ่มจากถาม trigger, input, output, data classification, decision owner และความเสี่ยง กำหนด DEFAULT/ASK/NEVER/ESCALATE พร้อม verification, stop condition, fallback และ run record สร้าง test cases ทั้งปกติและ failure cases ห้ามย้ายไฟล์ ส่งข้อมูล เปลี่ยน permission หรือเชื่อมบริการภายนอกจนกว่าฉันอนุมัติขอบเขตชัดเจน

ชิ้นงานและเกณฑ์ผ่าน

ชุดที่คนอื่นตรวจได้ และคุณกลับมาใช้ได้
