Module 0 · Before class

Prepare Your
AI Research Workspace

ติดตั้งครั้งเดียว เปิดมาเจอหน้า AI และตรวจว่าเครื่องพร้อมทำกิจกรรมจริง

Step 1

ตรวจเครื่องก่อนดาวน์โหลด

OSWindows 11
หรือ supported macOS
Memory8 GB minimum
16 GB recommended
Storage20 GB
free space
AccessInstall permission
+ stable internet

Chromebook, tablet และเครื่องที่ติดตั้งซอฟต์แวร์ไม่ได้ไม่เหมาะกับกิจกรรมนี้

Step 2

เลือกเครื่องที่คุณใช้

Windows

Windows 11 · 64-bit

ติดตั้งผ่าน PowerShell และ WinGet พร้อม VS Code learner profile และ starter project

WSL2 ไม่ใช่ค่าเริ่มต้น

macOS

Apple silicon / Intel

script จะตรวจ architecture และเลือก installation path ที่ผ่านการทดสอบ

ไม่ติดตั้ง Rosetta หรือ Homebrew โดยไม่ขออนุญาต

Step 3

สิ่งที่ต้องทำให้ผ่าน

  1. 01เปิด VS Code แล้วพบหน้า AI agent
  2. 02แก้และ preview ไฟล์ Markdown
  3. 03ให้ agent อ่านและสร้างไฟล์ใน project
  4. 04สร้าง PDF และอ่านข้อความกลับจาก PDF
  5. 05ส่ง readiness evidence ก่อนวันอบรม
ยังไม่ต้องติดตั้งตอนนี้: installer และรายการ software ที่ผ่าน compatibility test จะเปิดให้ดาวน์โหลดก่อนรอบ pilot
