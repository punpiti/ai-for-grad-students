รู้จัก Terminal / CLI

Terminal คืออะไร?

Terminal คือช่องสำหรับบอกคอมพิวเตอร์ให้ทำงานด้วยข้อความ ส่วน CLI หรือ Command-Line Interface คือโปรแกรมที่เราเรียกใช้ผ่านช่องนี้ หนึ่งบรรทัดคือหนึ่งคำสั่ง ในกิจกรรมนี้ไม่ต้องจำคำสั่งและไม่ต้องพิมพ์เอง—อ่านก่อน กด Copy วาง แล้วกด Enter

Windows 11

เปิด PowerShell แบบปกติ

  1. 1
    กดปุ่ม Windows บน keyboard หรือคลิก Start
  2. 2
    พิมพ์ PowerShell
  3. 3
    คลิก Windows PowerShell หรือกด Enter
  4. 4
    ตรวจ title bar ต้องไม่มีคำว่า Administrator

พร้อมเมื่อเห็น PS C:\Users\ชื่อผู้ใช้>

ตัวอย่าง PowerShellPS C:\Users\student> ▌PS = PowerShell · C:\Users\student = โฟลเดอร์ปัจจุบัน · ▌ = จุดวางคำสั่ง
  • Paste: Ctrl+V
  • Run: กด Enter แล้วรอจนเห็น PS ...> กลับมา
  • Stop: กด Ctrl+C แล้วเรียกผู้สอน
  • Safety: อ่านก่อนรัน และไม่วาง password/token

เปิด Terminal

  4. 4
    ใช้หน้าต่างปกติ ไม่พิมพ์ sudo ในขั้นนี้

  • Paste: Command (⌘)+V
  • Run: กด Enter แล้วรอจนเห็น % หรือ $ กลับมา
  • Stop: กด Control+C แล้วเรียกผู้สอน
  • Safety: อ่านก่อนรัน และไม่วาง password/token

ต้องเลือกตามบัญชีที่มีอยู่ก่อน จึงจะเปิดขั้นตอนติดตั้งและแสดงคำสั่ง CLI ที่ตรงกับ AI นั้น

ยังไปต่อไม่ได้: กรุณาเลือก AI หนึ่งตัว

ขั้นที่ 2 · Installation

ติดตั้งซอฟต์แวร์

Installer จะเตรียม AI workspace, เครื่องมืออ่านเอกสารและ OCR ไทย–อังกฤษ, Markdown และ PDF ให้พร้อมในครั้งเดียว โดยติดตั้งเพิ่มเฉพาะสิ่งที่ยังไม่มี

สบายใจได้: Script ไม่เก็บรหัสผ่านหรือ token และไม่ปิดระบบป้องกันของเครื่อง
ถ้ารันซ้ำหรือแก้ปัญหา: ต้องคัดลอกคำสั่งโหลด Script ในข้อ 1 ใหม่ก่อนเสมอ แล้วตรวจว่าเห็น SETUP_VERSION 2026.08.05.6 เพื่อไม่ใช้ไฟล์เก่าที่ค้างใน Downloads

Windows 11

Admin system installation

1 เปิด PowerShell ด้วย Run as administrator แล้วโหลด script

curl.exe -fL "https://punpiti.github.io/ai-for-research/downloads/setup-windows.ps1" -o "$HOME\Downloads\setup-windows.ps1"

2 รัน script ใน Admin PowerShell

powershell -ExecutionPolicy Bypass -File "$HOME\Downloads\setup-windows.ps1" -Mode InstallSystem -Agent codex

เมื่อเครื่องพร้อมจะเห็น FINAL_RESULT PASS และหน้าต่างนี้จะปิดเองหลังติดตั้งเสร็จ

3 เปิด PowerShell ปกติและเตรียม Workspace

powershell -ExecutionPolicy Bypass -File "$HOME\Downloads\setup-windows.ps1" -Mode SetupUser -Agent codex

ขั้นนี้ต้องใช้ PowerShell ปกติ Script ต้องแสดง FONT_READY ก่อนเริ่มติดตั้ง AI frontend แล้วจึงเตรียม Workspace, PDF Viewer และเครื่องมือนำเข้าเอกสาร หากฟอนต์ไม่ครบ Script จะหยุดทันที หากเลือก Antigravity ไม่จำเป็นต้องมีคำสั่ง agy-ide

macOS

System installation

1 โหลด script

curl -fL "https://punpiti.github.io/ai-for-research/downloads/setup-macos.sh" -o "$HOME/Downloads/setup-macos.sh"

2 รัน script; ระบบขอสิทธิ์เมื่อจำเป็น

AI_GRAD_AGENT=codex bash "$HOME/Downloads/setup-macos.sh" --install-system

script ตรวจเครื่องก่อน หากไม่ผ่านจะหยุดโดยไม่ติดตั้ง หากผ่านจึงขอรหัสผ่านเฉพาะขั้นที่จำเป็น

3 เปิด Terminal ปกติใหม่และติดตั้ง AI frontend

AI_GRAD_AGENT=codex bash ~/Downloads/setup-macos.sh --setup-user

ต้องเห็น SETUP_VERSION 2026.08.05.6 และ FONT_READY หากเลือก Codex หรือ Claude จะเห็น CREATE VS_CODE_PROFILE ด้วย เมื่อเสร็จแล้ว Script จะเปิด Workspace ใน VS Code ให้อัตโนมัติ หาก PATH ยังไม่ refresh Script จะหยุดและให้เปิด Terminal ใหม่ โดยไม่แสดงผลสำเร็จผิด ๆ

Linux / WSL2

System installation

1 โหลด script

curl -fL "https://punpiti.github.io/ai-for-research/downloads/setup-linux.sh" -o "$HOME/Downloads/setup-linux.sh"

2 รัน script; ระบบเรียก sudo เมื่อจำเป็น

AI_GRAD_AGENT=codex bash "$HOME/Downloads/setup-linux.sh" --install-system

script ตรวจเครื่องก่อน หากไม่ผ่านจะหยุดโดยไม่ติดตั้ง หากผ่านจึงเรียก sudo เฉพาะ package ที่จำเป็น

3 เปิด Terminal/Ubuntu ปกติใหม่และติดตั้ง AI frontend

AI_GRAD_AGENT=codex bash ~/Downloads/setup-linux.sh --setup-user

AI workspace, PDF Viewer และโฟลเดอร์งานพร้อมเครื่องมือนำเข้าเอกสารถูกติดตั้งในบัญชีผู้ใช้ปกติโดยไม่ใช้ sudo

ติดตั้งสำเร็จเมื่อ: เห็น FINAL_RESULT PASS และมีโฟลเดอร์งานพร้อม Pandoc, PDF และ OCR ภาษาไทย–อังกฤษ หากยังไม่สำเร็จ Script จะบอกสิ่งที่ต้องทำต่อให้

ขั้นที่ 3

ตรวจว่า Workspace เปิดแล้ว

คำสั่ง --setup-user จะเปิด Workspace ให้อัตโนมัติ หากเห็นโฟลเดอร์งานใน VS Code แล้ว ไม่ต้องเปิดซ้ำ ให้ไปที่ “เชื่อมต่อบัญชี AI” ได้เลย วิธีด้านล่างใช้เมื่อปิดหน้าต่างไปแล้วหรือต้องการเปิดใหม่เท่านั้น

Workspace ไม่เปิดอัตโนมัติ? ดูวิธีเปิดใหม่

Windows 11

เปิดด้วย PowerShell

  1. 1
    เปิด PowerShell แบบปกติ
  2. 2
    คัดลอกคำสั่งด้านล่างแล้วกด Enter
  3. 3
    รอให้ VS Code เปิดโฟลเดอร์งาน
code --profile "AI for Research - codex" "$HOME\ai-for-research-workspace"

เปิดผ่าน Antigravity IDE

  1. 1
    เปิด Antigravity จาก Start menu และ Sign in ด้วยบัญชี Google
  2. 2
    เลือก File → Open Folder
  3. 3
    วาง path ด้านล่าง แล้วกด Select Folder
%USERPROFILE%\ai-for-research-workspace

ถ้า PDF Viewer ยังไม่มี ให้เปิด Extensions ใน IDE แล้วติดตั้ง mathematic.vscode-pdf

macOS

หาก Workspace ยังไม่เปิด

  1. 1
    เปิด VS Code
  2. 2
    กด Command (⌘) + O
  3. 3
    กด Command (⌘) + Shift + G
  4. 4
    วางตำแหน่งโฟลเดอร์ด้านล่าง กด Enter แล้วกด Open
~/ai-for-research-workspace

หาก Antigravity Workspace ยังไม่เปิด

  1. 1
    เปิด Terminal ไม่ใช่ช่องค้นหาโฟลเดอร์ใน Antigravity
  2. 2
    คัดลอกคำสั่งด้านล่างแล้วกด Enter
  3. 3
    รอให้ Antigravity IDE เปิดโฟลเดอร์งาน
agy-ide "$HOME/ai-for-research-workspace"

เชื่อมต่อบัญชี AI

  1. 01

  2. 02

รายละเอียดจากผู้ให้บริการ: คู่มือ Codex ของ OpenAI

พร้อมไปต่อเมื่อ: Sign in สำเร็จและเห็นช่องสนทนาใน AI panel

ทดลอง Prompt แรก

  1. 01
    คัดลอก Prompt
    ใช้ข้อความสั้น ๆ ด้านล่าง โดยยังไม่ต้องเปิด Terminal หรือไฟล์ใด
    แนะนำตัวสั้น ๆ แล้วบอกว่าคุณช่วยงานวิจัยใน Workspace นี้ได้อย่างไร 3 ข้อ โดยยังไม่แก้ไขไฟล์ใด
  2. 02
    ส่งให้ AI
    วางข้อความใน Codex panel แล้วกด Enter
  3. 03
    ตรวจคำตอบ
    ต้องได้รับคำแนะนำ 3 ข้อ และ AI ต้องยังไม่สร้างหรือแก้ไขไฟล์
Prompt แรกผ่านเมื่อ: AI ตอบกลับได้และทำตามเงื่อนไข “ยังไม่แก้ไขไฟล์ใด” จากนั้นจึงเริ่มทดลอง Markdown

ทดลองไฟล์ Markdown แรก

  1. 01
    เปิดและแก้ Markdown
    คลิก content.md แล้วแก้ข้อความตัวอย่าง
  2. 02
    ดู Markdown Preview
    กด Ctrl+Shift+V (macOS: Command+Shift+V) เพื่อดูผลลัพธ์ที่จัดรูปแบบแล้ว
  3. 03
    ให้ AI อ่านและสร้าง PDF
    วาง prompt ด้านล่างใน Codex panel; agent จะอ่านคำสั่งใน Workspace และใช้ Integrated Terminal เบื้องหลังเมื่อจำเป็น
    อ่าน content.md แล้วสร้าง output/content.pdf ตามรูปแบบที่กำหนดไว้ใน Workspace โดยไม่เปลี่ยนไฟล์ต้นฉบับ จากนั้นตรวจว่าไฟล์ PDF สร้างสำเร็จ
  4. 04
    อนุญาตเฉพาะ Pandoc
    หาก IDE ถาม Allow running this command? ให้เลือก Yes, and always allow “pandoc” สำหรับ Workspace ของรายวิชานี้ ไม่เลือกอนุญาต shell หรือทุกคำสั่งแบบกว้าง
  5. 05
    เปิด PDF
    คลิก output/content.pdf และตรวจว่าเปิดอ่านได้ เป็นกระดาษ A4 ภาษาไทยใช้ Sarabun จาก Google Fonts ที่ติดตั้งพร้อม Workspace และมีรูปแบบสีตาม template
