รู้จัก Terminal / CLI

Terminal คืออะไร?

Terminal คือช่องสำหรับบอกคอมพิวเตอร์ให้ทำงานด้วยข้อความ ส่วน CLI หรือ Command-Line Interface คือโปรแกรมที่เราเรียกใช้ผ่านช่องนี้ หนึ่งบรรทัดคือหนึ่งคำสั่ง ในกิจกรรมนี้ไม่ต้องจำคำสั่งและไม่ต้องพิมพ์เอง—อ่านก่อน กด Copy วาง แล้วกด Enter

ชื่อโฟลเดอร์และเครื่องหมายรอรับคำสั่งPS C:\Users\student> ▌เครื่องหมาย ▌ คือจุดที่คำสั่งจะถูกวาง
  • Paste: PowerShell ใช้ Ctrl+V · macOS ใช้ Command+V · Linux/WSL2 มักใช้ Ctrl+Shift+V
  • Run: กด Enter หนึ่งครั้ง แล้วรอจนเห็น prompt กลับมา
  • Stop: หากคำสั่งค้างหรือรันผิด ให้กด Ctrl+C แล้วเรียกผู้สอน
  • Safety: รันเฉพาะคำสั่งบนหน้าเรียน อ่านก่อนทุกครั้ง และไม่วาง password/token ลงใน terminal

เลือกเครื่อง

ฝึกคำสั่งแรกก่อนติดตั้ง

Windows

Windows 11 · 64-bit

  1. กดปุ่ม Windows พิมพ์ PowerShell แล้วกด Enter — ไม่ต้องเลือก Run as administrator
  2. ฝึก Copy → Ctrl+V → Enter ด้วยสองคำสั่งแรก
  3. กดดาวน์โหลด installer แล้วใช้คำสั่ง Check ใน PowerShell ปกติ
  4. เปิด Admin PowerShell เพื่อติดตั้ง system tools; เมื่อเสร็จหน้าต่างจะปิดเอง
  5. เปิด PowerShell ปกติอีกครั้ง แล้วติดตั้งส่วนของผู้ใช้

ฝึก 1 · ตอนนี้อยู่ที่ไหน

Get-Location

ฝึก 2 · ดูไฟล์ในโฟลเดอร์

Get-ChildItem

ควรเห็น: path ปัจจุบันและรายชื่อไฟล์ โดยยังไม่มีอะไรถูกแก้ไข

ดาวน์โหลด PowerShell script

1 · ตรวจเครื่อง

powershell -ExecutionPolicy Bypass -File "$HOME\Downloads\setup-windows.ps1" -Mode Check

2 · เปิด PowerShell ด้วย Run as administrator แล้วติดตั้ง system tools

powershell -ExecutionPolicy Bypass -File "$HOME\Downloads\setup-windows.ps1" -Mode InstallSystem

เมื่อเสร็จ: Admin PowerShell จะปิดเองภายใน 5 วินาที ห้ามเปิด agent หรือสร้างงานในหน้าต่าง Admin

3 · เปิด PowerShell แบบปกติใหม่ แล้วตั้งค่าส่วนของผู้ใช้

powershell -ExecutionPolicy Bypass -File "$HOME\Downloads\setup-windows.ps1" -Mode SetupUser -Agent codex

ระบบป้องกัน: หากเปิด PowerShell แบบ Admin อยู่ Script จะหยุดและสั่งให้เปิดหน้าต่างปกติใหม่

WSL2 ไม่ใช่ค่าเริ่มต้น

macOS

Apple silicon / Intel

  1. กด Command+Space พิมพ์ Terminal แล้วกด Enter
  2. ฝึก Copy → Command+V → Enter ด้วยสองคำสั่งแรก
  3. กดดาวน์โหลด installer แล้วใช้คำสั่ง Check
  4. อ่านผล PASS/MISSING ก่อนใช้คำสั่ง Install

ฝึก 1 · ตอนนี้อยู่ที่ไหน

pwd

ฝึก 2 · ดูไฟล์ในโฟลเดอร์

ls

ควรเห็น: path ปัจจุบันและรายชื่อไฟล์ โดยยังไม่มีอะไรถูกแก้ไข

ดาวน์โหลด macOS script

1 · ตรวจเครื่อง

bash "$HOME/Downloads/setup-macos.sh" --check

2 · ติดตั้ง

AI_GRAD_AGENT=codex bash ~/Downloads/setup-macos.sh --install

ควรเห็น: macOS version, architecture และรายการ PASS/MISSING

ไม่ติดตั้ง Rosetta หรือ Homebrew โดยไม่ขออนุญาต

Linux / WSL2

Ubuntu / Debian / WSL2 · 64-bit

  1. Linux: เปิดแอป Terminal · WSL2: เปิด Ubuntu จาก Start menu
  2. ฝึก Copy → Ctrl+Shift+V → Enter ด้วยสองคำสั่งแรก
  3. กดดาวน์โหลด installer; ใน WSL2 ให้อาจารย์ช่วยหา path ของ Downloads หากคำสั่งตัวอย่างหาไฟล์ไม่พบ
  4. อ่านผล PASS/MISSING ก่อนใช้คำสั่ง Install

ฝึก 1 · ตอนนี้อยู่ที่ไหน

pwd

ฝึก 2 · ดูไฟล์ในโฟลเดอร์

ls

ควรเห็น: path ปัจจุบันและรายชื่อไฟล์ โดยยังไม่มีอะไรถูกแก้ไข

ดาวน์โหลด Linux / WSL2 script

1 · ตรวจเครื่อง (Linux native)

bash "$HOME/Downloads/setup-linux.sh" --check

2 · ติดตั้ง

AI_GRAD_AGENT=codex bash ~/Downloads/setup-linux.sh --install

ควรเห็น: platform=Linux หรือ platform=WSL2 ตามเครื่องที่ใช้

Script ตรวจ WSL2 ได้ แต่จะไม่เปิด WSL2 หรือติดตั้ง VS Code ฝั่ง Windows ให้โดยอัตโนมัติ

Readiness practice

ฝึกให้ผ่านทีละข้อ

  1. 01
    เปิด VS Code
    คัดลอกคำสั่งนี้ลง terminal เพื่อเปิด workspace
    code "$HOME/ai-for-grad-students-workspace"
  2. 02
    เปิด terminal ใน VS Code
    เลือกเมนู Terminal → New Terminal จะเห็นช่องคำสั่งด้านล่าง ไม่ต้องรู้คำสั่งอื่นนอกจากที่ให้คัดลอก
  3. 03
    เปิด agent
    คัดลอกคำสั่งด้านล่างเพื่อเปิด Codex แล้วทำตามหน้า sign in; ห้ามส่ง token ให้ผู้สอน
    codex
  4. 04
    Markdown
    คลิก content.md แก้ข้อความ แล้วกด Ctrl+Shift+V (macOS: Command+Shift+V) เพื่อเปิด Preview
  5. 05
    Agent file task
    อ่าน content.md แล้วสร้าง output/readiness-note.md โดยไม่เปลี่ยนไฟล์ต้นฉบับ
  6. 06
    Evidence
    บันทึกผล check, screenshot ของ workspace และ readiness note โดยตรวจว่าไม่มีข้อมูลลับ

การบ้าน

เปิดซ้ำด้วยตัวเองและเตรียมคาบถัดไป

ทบทวน

ปิดแล้วเปิด VS Code ใหม่ รัน script ในโหมด check และยืนยันว่า workspace, agent และ Markdown ยังทำงาน

แก้สิ่งที่ค้าง

ถ้ายังมีรายการ MISSING ให้บันทึก error ตามจริง ใช้ fallback ในชั้น และนัด setup clinic โดยไม่ปิด security protection

เตรียมคาบถัดไป

เก็บ research excerpt ที่เปิดเผยได้ใน input/ และเขียนรายการงานที่อยากให้ AI ช่วยใน content.md

หลักฐานที่ส่ง: ผล check, readiness-note.md และคำอธิบาย blocker ถ้ามี ไม่ส่ง password, token, API key หรือข้อมูลวิจัยที่ห้ามเปิดเผย
