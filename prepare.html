ช่วงบรรยาย · 10 นาที

รู้จัก workspace ก่อนติดตั้ง

VS Code

พื้นที่เปิดไฟล์ Markdown ดูผลลัพธ์ และเรียก agent

Agent

ช่วยทำงานในโฟลเดอร์ภายใต้สิทธิ์ที่ผู้เรียนกำหนด

Course tools

Python, Pandoc และ LaTeX ทำงานเบื้องหลัง ไม่ต้องเขียนโค้ดเอง

หลักความปลอดภัย: อ่านสิ่งที่ script จะติดตั้งก่อนกดยืนยัน Script ไม่เก็บ token ไม่ปิดระบบป้องกัน และไม่ติดตั้ง WSL2 หรือ Rosetta อัตโนมัติ

เลือก agent ที่คุณมีเพียงหนึ่งตัว

Agent อื่นถือเป็น advanced track และไม่ครอบคลุมใน Module 1

Workshop · 35 นาที

เลือกแพลตฟอร์มแล้วทำตามขั้นตอน

Windows

Windows 11 · 64-bit

เปิด PowerShell ปกติ ดาวน์โหลด script แล้วตรวจเครื่องก่อนติดตั้ง

ดาวน์โหลด PowerShell script
powershell -ExecutionPolicy Bypass -File .\setup-windows.ps1 -Mode Check
powershell -ExecutionPolicy Bypass -File .\setup-windows.ps1 -Mode Install -Agent codex
WSL2 ไม่ใช่ค่าเริ่มต้น

macOS

Apple silicon / Intel

เปิด Terminal ดาวน์โหลด script และรัน check ก่อน Script จะไม่ติดตั้ง Homebrew หรือ Rosetta ให้เอง

ดาวน์โหลด macOS script
bash ~/Downloads/setup-macos.sh --check
AI_GRAD_AGENT=codex bash ~/Downloads/setup-macos.sh --install
ไม่ติดตั้ง Rosetta หรือ Homebrew โดยไม่ขออนุญาต

Linux

Ubuntu / Debian · 64-bit

ใช้ apt และใช้ snap สำหรับ VS Code เมื่อมีอยู่ ไม่เปิด WSL2 ให้โดยอัตโนมัติ

ดาวน์โหลด Linux script
bash ~/Downloads/setup-linux.sh --check
AI_GRAD_AGENT=codex bash ~/Downloads/setup-linux.sh --install
ผู้ใช้ WSL2 ต้องติดตั้ง VS Code ฝั่ง Windows และเปิด WSL2 เอง

Readiness practice

ฝึกให้ผ่านทีละข้อ

  1. 01
    เปิด workspace
    เปิดโฟลเดอร์ ai-for-grad-students-workspace ใน VS Code
  2. 02
    Sign in
    เปิด Codex แล้วรัน codex login; ลงชื่อเข้าใช้ผ่าน browser และห้ามส่ง token ให้ผู้สอน
  3. 03
    Markdown
    แก้ content.md และเปิด Markdown Preview
  4. 04
    Agent file task
    สั่ง agent: “อ่าน content.md แล้วสร้าง output/readiness-note.md โดยไม่เปลี่ยนไฟล์ต้นฉบับ”
  5. 05
    Evidence
    บันทึกผล check, screenshot ของ workspace และ readiness note โดยตรวจว่าไม่มีข้อมูลลับ

ความพร้อม: 0%

การบ้าน

เปิดซ้ำด้วยตัวเองและเตรียมคาบถัดไป

ทบทวน

ปิดแล้วเปิด VS Code ใหม่ รัน script ในโหมด check และยืนยันว่า workspace, agent และ Markdown ยังทำงาน

แก้สิ่งที่ค้าง

ถ้ายังมีรายการ MISSING ให้บันทึก error ตามจริง ใช้ fallback ในชั้น และนัด setup clinic โดยไม่ปิด security protection

เตรียมคาบถัดไป

เก็บ research excerpt ที่เปิดเผยได้ใน input/ และเขียนรายการงานที่อยากให้ AI ช่วยใน content.md

หลักฐานที่ส่ง: ผล check, readiness-note.md และคำอธิบาย blocker ถ้ามี ไม่ส่ง password, token, API key หรือข้อมูลวิจัยที่ห้ามเปิดเผย
