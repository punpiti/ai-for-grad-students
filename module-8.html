Document Production

เริ่มได้สองแบบ

ใช้ผลงานเดิม
หรือใช้ package ตัวอย่าง

ต่อจาก Module 5–7

นำ venue landscape, verified claims, ตาราง ภาพ และไฟล์อ้างอิงที่ตรวจแล้วมาใช้ ห้ามให้ AI สร้างผลหรือ citation เพื่อเติมช่องว่าง

Standalone

เตรียม official author guideline, template และเนื้อหาที่ตรวจแล้ว 1–2 หน้า หรือใช้ package ตัวอย่างของหลักสูตร

เลือกเครื่องมือจากข้อกำหนด

ถ้า venue ให้ Word template ให้รักษา Word; ถ้าให้ LaTeX ให้เริ่มจาก template ที่ compile ได้ ห้ามแปลงเพราะความชอบส่วนตัว

ซอฟต์แวร์: ใช้ Pandoc, LaTeX และเครื่องมือตรวจ PDF ที่ Module 1 เตรียมไว้แล้ว หาก build test ไม่ผ่านให้กลับไป Module 1 ก่อนเริ่ม

Insight to paragraph

AI เรียบเรียงได้
แต่นักวิจัยต้องให้ความหมาย

01

Statement

ประโยคหลักที่ผู้วิจัยยืนยันว่าหลักฐานรองรับ

02

Evidence

ตาราง ภาพ ค่า หรือแหล่งอ้างอิงพร้อมตำแหน่งที่ตรวจย้อนกลับได้

03

Explanation

เหตุผลหรือกลไกที่ผู้วิจัยรับผิดชอบ ไม่ใช่เรื่องที่ AI เดาเติม

04

Boundary

ข้อจำกัด ความไม่แน่นอน และสิ่งที่ข้อความนี้ไม่ควรถูกนำไปกล่าวอ้าง

Build ladder

ผ่านทีละ Gate

  1. 00
    Verify venue package
    บันทึก URL วันที่ version และ checksum ของ guideline/template เมื่อทำได้
  2. 01
    Pristine template
    เปิดหรือ compile ต้นฉบับเดิมให้ผ่านก่อนแก้ เพื่อแยกปัญหา environment ออกจากปัญหาเนื้อหา
  3. 02
    Outline and sections
    เพิ่มโครงและเนื้อหาทีละส่วน แล้ว build ทุกครั้งที่เปลี่ยนชั้นสำคัญ
  4. 03
    Citations, figures, tables
    ตรวจ identity/source ของ citation และเชื่อมภาพ/ตารางกับไฟล์ข้อมูลต้นทาง
  5. 04
    Full build and PDF QA
    ตรวจหน้า ล้นขอบ ฟอนต์ ภาษาไทย ตาราง ภาพ caption reference และข้อกำหนด venue
  6. 05
    Presentation variant
    สร้างโปสเตอร์หรือสไลด์จาก verified claims ชุดเดียวกัน แล้วซ้อมตามเวลาและผู้ฟังจริง
ใช้ official guideline และ template ที่ให้เป็นข้อกำหนดหลัก ตรวจ pristine template ก่อน แล้วเสนอ build plan แบบทีละ gate ใช้เฉพาะ verified claims, citations, figures และ tables ที่ฉันระบุ ทุกย่อหน้าต้องย้อนกลับไปยัง paragraph contract ได้ ห้ามสร้างผล อ้างอิง หรือคำอธิบายกลไกเพิ่มเอง หลัง build ให้ตรวจ PDF ทั้งเชิงเนื้อหาและภาพ

ชิ้นงานและเกณฑ์ผ่าน

เอกสารที่ตรง venue และย้อนกลับถึงหลักฐาน

การบ้าน: ให้ผู้ร่วมงานตรวจ source-to-PDF package และบันทึกข้อผิดพลาดที่ต้องป้องกันใน workflow ส่วนบุคคล
