ใช้ AI ช่วยเขียนและรัน Python โดยผู้เรียนไม่จำเป็นต้องเขียนโปรแกรมเอง แต่ต้องตรวจไฟล์นำเข้า DataFrame วิธีวิเคราะห์ ภาพ และข้อสรุปทุกขั้น

เตรียมข้อมูล

เลือกหนึ่งในสี่ทาง

Classification

ใช้ข้อมูลตัวอย่างแบบ Iris เพื่อเรียนรู้ feature, label, train/test split และ confusion matrix

Survey

ใช้ CSV, Excel หรือ SPSS ที่มี data dictionary และนิยาม missing value ชัดเจน

Reproduce

เลือกบทความที่เปิดข้อมูล แล้วทำซ้ำตารางหรือภาพหนึ่งชิ้นโดยบันทึกความต่างจากต้นฉบับ

Your data

ใช้ข้อมูลของตนเองเมื่อมีสิทธิ์และผ่านการตัดข้อมูลระบุตัวบุคคลแล้ว หากไม่พร้อมให้ใช้ข้อมูลตัวอย่าง

ซอฟต์แวร์: ใช้ Python และไลบรารีที่ Module 1 เตรียมให้ ได้แก่ pandas, Matplotlib, Seaborn, Plotly และ scikit-learn ไม่ต้องติดตั้งเพิ่มระหว่างเรียน หาก readiness check ไม่ผ่านให้กลับไป Module 1

จากแฟ้มดิบไปสู่ภาพ

01

Import receipt

บันทึกชนิดแฟ้ม encoding, delimiter, sheet, header, row/column count, type และ missing value

02

Four DataFrames

แยก raw_df, clean_df, analysis_df และ plot_df เพื่อไม่เขียนทับหลักฐานดิบ

03

Hypothesis & method

กำหนดคำถาม ตัวแปร หน่วยวิเคราะห์ วิธี และสมมติฐานก่อนดูผลที่ชอบ

04

Visual encoding

ผูกคอลัมน์กับ x, y, color, size, style, facet และ tooltip ตามชนิดข้อมูลและคำถาม

05

Plot data

ส่งออก plot-data.csv เพื่อให้ตรวจค่าที่อยู่หลังภาพได้ ไม่ใช้ภาพเป็นหลักฐานเพียงอย่างเดียว

06

QA

ตรวจ denominator, aggregation, scale, uncertainty, accessibility และ claim fit ก่อนตีความ

Workshop

สร้างตาราง ภาพ และหลักฐานการรัน

  1. 01
    ตรวจแฟ้มนำเข้า
    สร้าง import-report.md และ data-dictionary.csv ก่อนแปลงข้อมูล
  2. 02
    สร้าง DataFrame bridge
    แสดงจำนวนแถว คอลัมน์ ชนิดข้อมูล missing, duplicate และการเปลี่ยน wide/long หรือ aggregation
  3. 03
    วิเคราะห์ตามสมมติฐาน
    บันทึก generated script, parameters, Python/library versions, warnings และ random seed เมื่อเกี่ยวข้อง
  4. 04
    สร้างภาพสองแบบ
    ทำภาพนิ่งด้วย Seaborn/Matplotlib และภาพโต้ตอบด้วย Plotly จาก plot_df เดียวกัน
  5. 05
    Red-team interpretation
    แยกสิ่งที่ข้อมูลแสดง สิ่งที่เป็นการตีความ ข้อจำกัด และสิ่งที่ยังตอบไม่ได้
ตรวจแฟ้มข้อมูลนี้แบบอ่านอย่างเดียวก่อน สร้าง import report และ data dictionary แล้วเสนอแผน raw_df → clean_df → analysis_df → plot_df ให้ฉันอนุมัติ จากนั้นจึงสร้าง script ที่รันซ้ำได้ ตาราง plot-data.csv ภาพนิ่งและภาพโต้ตอบ พร้อมบันทึกเวอร์ชัน พารามิเตอร์ warning และข้อจำกัด ห้ามเขียนทับแฟ้มดิบหรือสรุปเหตุเป็นผลจากความสัมพันธ์
